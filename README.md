# LangJP - Hiragana Matrix 🇯🇵

Ứng dụng web tĩnh hỗ trợ học và ghi nhớ bảng chữ cái Hiragana tiếng Nhật theo cơ chế **Tự điền ma trận 2 chiều (2-Way Grid Fill Challenge)**.

---

## 🌟 Tính năng nổi bật
- **Bảng chữ cái đầy đủ:** 46 chữ cơ bản (Gojuon), 25 chữ âm đục (Dakuten/Handakuten), 33 chữ âm ghép (Yoon).
- **Bộ chọn phạm vi linh hoạt:** Tự do tick chọn từng hàng chữ cái muốn ôn tập.
- **3 Chế độ tương tác:**
  1. 📖 **Xem & Ôn tập Bảng:** Ôn tập mặt chữ và phát âm Romaji trước khi test.
  2. ⌨️ **Điền Romaji (Nhật ➔ Cách đọc):** Tự gõ cách đọc vào bảng, tự động nhảy ô (Auto-advance) khi gõ đúng.
  3. 🧩 **Điền Hiragana (Cách đọc ➔ Chữ Nhật):** Khay chữ cái xáo trộn, bấm chọn để lấp đầy bảng.
- **2 Chế độ chấm điểm:**
  - ✨ **Kiểm tra tức thì (Zen Mode):** Báo đúng/sai ngay lập tức.
  - ⏱️ **Thử thách tính giờ (Test Mode):** Bấm giờ hoàn thành và xem tổng kết chi tiết câu sai.
- **Mobile Responsive 100%:** Thiết kế mượt mà, tối ưu trên điện thoại và máy tính.
- **Giao diện hiện đại:** Hỗ trợ cả Dark Mode & Light Mode phong cách Nhật Bản.

## 🚀 Hướng dẫn kích hoạt GitHub Pages
1. Vào **Settings** của repository trên GitHub.

3. Ở phần **Branch**, chọn `main` / `root` và nhấn **Save**.
